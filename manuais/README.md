# Manuais | PRISMA-COI

Esta pasta reúne manuais de utilização das ferramentas operacionais.

## Análise de Logger (Módulo 4.4)

**Arquivo oficial:** `Manual_de_Uso_Analise_de_Logger_PRISMA_COI_Aegea.pdf`

O botão **📘 Baixar manual de utilização (PDF)**, na barra lateral
de `pages/4_4_Analise_de_Logger.py`, lê diretamente esse PDF versionado
no repositório. Não é necessário acessar um serviço externo para fazer o
download.

A nomenclatura da pasta **`manuais`** está em letras minúsculas
e deve ser mantida nos caminhos da aplicação: ambientes Linux
distinguem maiúsculas e minúsculas.

A integridade do arquivo é verificada na integração contínua
por meio de um teste de cabeçalho, tamanho e hash SHA-256.

**Nota de operação:** a implantação do PRISMA deve incluir esta pasta
no mesmo diretório raiz do aplicativo. Se não houver PDF, o botão
será desativado e uma orientação será exibida.
