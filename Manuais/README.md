# Manuais | PRISMA-COI

Diretório para manuais de utilização das ferramentas operacionais do PRISMA-COI.

## Análise de Logger

**Arquivo esperado:**

`Manual_de_Uso_Analise_de_Logger_PRISMA_COI_Aegea.pdf`

O botão **Baixar manual de utilização (PDF)** da sidebar da página
`pages/4_4_Analise_de_Logger.py` lê este PDF diretamente do
repositório durante a execução do Streamlit.

### Publicação

Adicionar o PDF com o nome acima diretamente nesta pasta, preservando
seu conteúdo e extensão. O arquivo deverá ter cabeçalho de PDF
(`%PDF-`) e ser mantido sob controle de versão. O aplicativo não faz
download de conteúdo externo, não gera manuais dinamicamente e não
depende de serviços de terceiros para esse recurso.

**Atenção:** apenas a presença do arquivo real habilita o download;
a interface não apresenta um link que possa retornar 404.
